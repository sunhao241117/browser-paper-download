# Browser Paper Download Skill

批量学术论文 PDF 自动下载工具，通过浏览器自动化技术，利用机构访问权限批量下载学术文献 PDF。

## 功能特性

### 核心功能
- **批量 DOI/PMID 处理**：支持从 CSV 导出文件中提取 DOI，批量查询 PMID 并下载 PDF
- **多出版商支持**：覆盖 PMC、Elsevier/ScienceDirect、OUP、Nature、Wiley、ACS、AACR 等主流出版商
- **机构登录集成**：支持郑州大学 CARSI 统一身份认证，自动完成机构登录
- **反机器人处理**：自动处理 Cloudflare Turnstile 人机验证
- **智能跳过机制**：自动识别并跳过已知无权限的期刊，避免重复失败尝试

### 自动化流程
1. **PMC 文献优先**：优先处理 PMC 开放获取文献，通过 PMC 文章页 → Download PDF 按钮下载
2. **非 PMC 文献**：通过 PubMed → 出版商全文链接 → 机构登录 → View PDF → 保存 PDF
3. **验证机制**：下载后自动验证 `%PDF-` 文件头，确保是真实 PDF 文件而非 HTML 页面
4. **批量重命名**：自动按 `PMID_<pmid>.pdf` 格式命名并移动到目标文件夹

### 下载策略
- **优先级排序**：先处理 PMC 文献（成功率最高），再处理其他期刊
- **已知无权限期刊预筛**：根据历史经验，预先跳过已知无权限的期刊
- **超时处理**：页面加载超时自动刷新一次，仍超时则跳过
- **全程自动化**：无需人工干预，自动处理决策和问题

## 技术实现

### 支持的下载方式
- **PMC**：导航文章页 → 点击 Download PDF 按钮 → 等待下载 → 验证 → 移动
- **Elsevier/ScienceDirect**：PubMed → Elsevier 链接 → 机构登录 → View PDF → Ctrl+S 保存
- **其他出版商**：根据出版商类型自动选择最佳下载路径

### 关键经验总结
- 必须在 PDF 查看器页面按 Ctrl+S（不是文章页），否则保存的是 HTML
- 保存类型必须是 "WPS PDF 文档 (*.pdf)" 或 "PDF (*.pdf)"
- "Save to Zotero (PDF)" 不是下载按钮，是保存到文献管理器
- ScienceDirect 自定义 PDF 查看器 Ctrl+S 有时失败，可回退到 Ctrl+P 打印
- 连续下载多篇后速率限制，刷新或直接导航 PDF URL 可恢复

## 使用场景

适用于以下场景：
- 文献调研后批量下载参考文献 PDF
- 系统综述/Meta 分析前的文献收集
- 课题相关文献的批量获取
- 科研团队文献库建设

## 注意事项

- 仅用于合法的学术研究用途
- 依赖机构订阅权限，无权限的文献无法下载
- 请遵守各出版商的版权政策和使用条款
- 反机器人验证自动化成功率有限，复杂验证可能需要人工介入
